# Recipe photo shot list

One photo per recipe. Save each as the filename shown in `content/images/originals/` (the folder exists; it is gitignored on purpose, keep your own copies).

**Spec:** landscape 4:3, **1600 x 1200 px or larger** (the biggest size we serve is 1440 wide), JPG, one backdrop and one kind of light for every dish, the real portion as written, no filters. The build crops to 4:3 and makes the web sizes.

When a photo is dropped in, tell Claude: it adds the `image.alt` line to the recipe and runs `npm run images:build`. Suggested alt text is below.
