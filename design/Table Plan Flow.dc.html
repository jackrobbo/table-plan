Save and checkout
A review step before the plan is saved. Plans always start the next Monday, whatever day the user signs up. One meal a week is new, tagged "New for you". As soon as they're happy, one tap goes to checkout (ingredients → basket, as 35 → 36). Every meal has a Swap that opens the similar-meals sheet (17).
